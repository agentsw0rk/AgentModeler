Wo und wie soll das toggle-bare linke Panel im Editor erscheinen?

A

Activity Bar + Panel (VS Code Style)

Schmale Icon-Leiste ganz links (wie VS Code Activity Bar), Code-Explorer Icon klappt ein breites Panel daneben auf/zu. Andere Icons könnten später folgen (z.B. Search, Git).

Flow

  • Links: User konfiguriert Server (Name, Transport, URL/Command, Env-Vars)
  • Env-Var Werte werden maskiert angezeigt und nur fuer Discovery genutzt — nie exportiert
  • "Discover Tools" schickt Config an Backend-Proxy → verbindet sich zum MCP-Server → gibt Tool-Liste zurueck
  • Rechts: Nach Discovery zeigt das Panel die Tool-Liste mit Namen und Beschreibungen
  • Die Tool-Tags erscheinen auch direkt auf dem Canvas-Node
  • "Re-Discover" erlaubt Aktualisierung wenn sich die Tool-Liste aendert

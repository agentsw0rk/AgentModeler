Konzept

  • MCP-Server-Nodes (cyan) haben einen Output-Port und verbinden sich zum Agent — wie Tools
  • Jeder Node zeigt: Server-Name, Transport + Endpoint, und entdeckte Tools als Tags
  • Nicht verbundene MCP-Server erscheinen ausgegraut mit gestricheltem Rand
  • Tool-Tags zeigen max. 4-5 Namen, dann "+N" fuer den Rest
  • MCP-Server koennen an Agent oder Sub-Agent gebunden werden

Planner Agent: UI-Zugang zur Konfiguration

Wie soll der Nutzer Goals, Actions und Planner-Settings bearbeiten?

A

Erweitertes Properties Panel

Goals, Actions, Planner-Config direkt im rechten Properties Panel (wie bei anderen Nodes). Tabs innerhalb des Panels trennen die Bereiche. Kompakt, aber potenziell eng bei vielen Actions.

B

Dedizierter Dialog / Modal

Klick auf den Planner-Node oeffnet einen grossen Dialog mit voller Breite. Mehr Platz fuer komplexe Action-Definitionen mit Preconditions/Effects. Aehnlich wie WorkspaceSettingsDialog.

C

Sliding Panel (von rechts)

Klick auf den Planner-Node schiebt ein breites Panel ueber das Canvas. Aehnlich wie ein Drawer/Sheet. Bleibt im Editor-Kontext, bietet aber mehr Platz als das Properties Panel.

Konzept

  • Sub-Agent-Nodes (lila) haben einen Output-Port und verbinden sich zum Haupt-Agent — genau wie Tools
  • Tools und Built-ins koennen an Sub-Agents angebunden werden (fetchTool → ResearchAgent, Filesystem → BookingAgent)
  • Gestrichelte Linien unterscheiden Delegation visuell von Tool-Bindings
  • Der Haupt-Agent bleibt der einzige Entry-Point
  • weatherTool ist direkt am Haupt-Agent — zeigt, dass beide Ebenen eigene Tools haben koennen
